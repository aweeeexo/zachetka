# Зачётка

## Этап 2. Статический лендинг

Папка [`docs/`](docs/) — публичная страница продукта на **чистых HTML, CSS и JavaScript**, без React и без сборки.

### Что есть на странице

- Название, проблема и ценностное предложение (первый экран и блок «Проблема»).
- Как работает продукт: три шага и скриншот экрана разбора.
- **Интерактивное демо**: вставляешь текст задания → получаешь этапы, сроки и пункты с номером строки-источника. Это упрощённый разбор на регулярных выражениях прямо в браузере (в приложении на этапе 4 его заменит AI).
- Возможности, макеты интерфейса, таблица сравнения с Notion, ChatGPT и LMS, тарифы, FAQ.
- Заметный призыв к действию: кнопки «Получить ранний доступ» и форма с почтой в конце страницы.

### Адаптивность

Bento-сетка перестраивается на трёх ширинах: десктоп (> 1080 px), планшет (≤ 900 px) и телефон (≤ 640 px). На телефоне меню сворачивается в кнопку, карточки идут в одну колонку, таблица сравнения прокручивается внутри своей карточки. Проверено на ширинах 375, 768 и 1440 px — горизонтальной прокрутки нет.

### Доступность

- Семантическая разметка: `header`, `nav`, `main`, `section` с `aria-labelledby`, `footer`, один `h1`, таблица с `caption` и `scope`.
- Ссылка «Перейти к содержимому» для навигации с клавиатуры, видимый фокус у всех интерактивных элементов.
- У всех полей формы есть `<label>`, ошибки выводятся рядом с полем и озвучиваются (`role="alert"`, `aria-invalid`, `aria-describedby`).
- У содержательных картинок есть `alt`, декоративные иконки скрыты от экранных читалок (`aria-hidden`).
- Кнопка меню сообщает своё состояние (`aria-expanded`), закрывается по `Esc`.
- Контраст текста не ниже 4.5:1; анимации отключаются при `prefers-reduced-motion`.

### JavaScript (`docs/main.js`)

1. Мобильное меню.
2. Плавное появление блоков при прокрутке (`IntersectionObserver`).
3. Демо-разбор задания: `parseAssignment(text)` находит заголовки «Этап N», строки «Срок сдачи: …» и пункты списков. Показаны состояния загрузки, пустого результата и ошибки.
4. Форма раннего доступа: проверка почты на клиенте, заявка сохраняется в `localStorage` (бэкенда на этом этапе нет).

### Дизайн

Цвета и шрифт — из презентации первого этапа: бирюзовый `#0D9488`, оранжевый акцент `#EA580C`, мятный фон `#F0FDFA`, тёмно-бирюзовый текст `#134E4A`, шрифт Inter. Все цвета заданы CSS-переменными в начале `styles.css`.

### Как открыть локально

Сборка не нужна — откройте `docs/index.html` в браузере. Или запустите локальный сервер из корня репозитория:

```bash
npx serve docs
# или
python -m http.server 8000 --directory docs
```

### Публикация

Лендинг публикуется через GitHub Pages прямо из папки `docs/` ветки `main` (Settings → Pages → Deploy from a branch → `main` / `/docs`). Сборка не нужна: после каждого push страница обновляется сама. Папка называется `docs`, потому что GitHub Pages умеет публиковать без настройки только корень репозитория или папку `docs/`.
